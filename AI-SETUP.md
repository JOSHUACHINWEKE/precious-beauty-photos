# Precious AI setup
Set GEMINI_API_KEY in Vercel Production environment variables. Optional GEMINI_MODEL overrides the default gemini-2.5-flash-lite; confirm model and free quota in AI Studio. Deploy this folder as a static project with Node serverless functions. Test on the deployed URL; Python http.server only serves static files and cannot run /api/chat. Never commit the key. For local integration testing use vercel dev with a securely configured development key.
Edit data/business-knowledge.json when confirmed business information changes; it does not sync with Firestore. Square is not configured. The AI does not send messages to the owner or confirm appointments. Tidio removed. Customers can call the studio. Google processes chat messages; verify current data terms and publish a privacy notice before launch. The per-instance IP rate limiter is best effort, not a global quota; configure durable rate limiting before public launch and monitor usage. Vercel Hobby is for noncommercial use; use eligible hosting for a commercial launch.
